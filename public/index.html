Frequently Asked Questions

Everything you need to know about QuickShare Pro

How long are files kept?

Files are kept only for the duration you choose when creating a room (1 hour, 24 hours, or 7 days). Once expired, or when you click "End session", all uploaded files and message records are immediately and permanently wiped from disk and memory.

How is access to my room secured?

Each room has an unambiguous 6-character code and a 6-digit PIN. Only visitors with both the code and the PIN (or who scan your private QR code) can view the feed. Authentication is verified server-side with HMAC-signed session cookies.

Do I need to install an app on my phone?

No installation is required. QuickShare runs entirely in any standard mobile browser (Safari, Chrome, Firefox). If you want faster access, you can add it to your Home Screen as a Progressive Web App (PWA).

What are the file size and room limits?

To ensure high performance for all users, rooms support up to 100 items, a total room quota of 200 MB, and a maximum single file size of 50 MB. Executables and dangerous script formats (.exe, .bat, .sh, etc.) are strictly prohibited.

Can I download all shared files at once?

Yes. The header includes a bulk download button that packages all active files in your room into a clean ZIP archive with a single click.

How do I report abuse or illegal content?

Visit our dedicated Report Abuse page to flag any violating room code. Our automated systems and administrators review flags promptly.
